# Notepad

A simple but powerful note-taking app built with HTML, CSS and JS. 

I started notepad as a simple, basic text editor, then grew it into a more powerful app with features like cloud saving, more editing modes and the best feature of all, collaboration.

### Try it out here: [https://notepad-psi.vercel.app/](https://notepad-theta-ten.vercel.app)

## Features

- 4 Editor Modes: Plain Text, Markdown, HTML, and Rich Text.
- Cloud Saving: I mean this is a must-have feature, leave your notes on one device and access them on another.
- Real time sync: Edit your notes on one device and see the changes on another device in real time.
The above two features are possible thanks to supaBase and the idea of cloud saving and real time sync was inspired by apple icloud notes.
- Collaboration: Share your notes with others and let them view or edit your notes. This is inspired by google docs
- Multiple Themes: Customize the look of your notepad with different themes. One of the themes is christamas and my fav is the dark theme(on an oled).
- Dynamic Island: totally not a copy of the dynamic island on the iphones. This features basically tells what action is performed(one by you, colloborator or the system)
- Keyboard Shortcuts: Use keyboard shortcuts to quickly perform action like saving, opening and more.
